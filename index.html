作品集

目前公開的兩個作品：一個遊戲資料庫網站，和一隻 Discord 機器人。

網站 · Next.js

hsr-database

崩壞：星穹鐵道角色與光錐資料庫網站。角色列表可以依命途、屬性、星級篩選，也支援名稱搜尋；角色詳情有技能說明和星魂效果，光錐詳情有各精煉等級的被動效果。Next.js + TypeScript + Tailwind CSS，資料更新至 4.6 版，部署於 Vercel。

Live Demo ↗ GitHub ↗ Ayaka-99 / hsr-database
機器人 · JavaScript

Discord 機器人

用 JavaScript 寫的 Discord 機器人，跑在 Google Cloud 的 VM 上。幫伺服器統計發言、管每日簽到，還有一套虛擬金庫經濟和德州撲克、21 點、大逃殺小遊戲。角色是星穹列車派對車廂的吧台機器人「閉嘴」，是第一個長期跑著的 side project。
